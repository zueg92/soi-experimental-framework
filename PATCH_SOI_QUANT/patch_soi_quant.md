# PATCH SOI-QUANT
## Layer Quantitativo Ascorbico

The PATCH SOI-QUANT is a quantitative stabilization layer inserted
between the Tension Index and the Kernel.

The patch does NOT decide buy/sell.
The patch transforms system tension into portfolio stability.

System flow:

Research Log
→ STS
→ Valuation / Narrative / Cycle / Technical
→ Tension Index
→ PATCH SOI-QUANT
→ Pressure Map + Stability Window
→ STS-OS
→ Kernel
→ Execution
→ Portfolio
